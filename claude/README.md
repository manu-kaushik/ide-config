# Claude Commands

Slash commands for [Claude Code](https://docs.anthropic.com/en/docs/claude-code).

## Installation

| Scope   | Path                    |
| ------- | ----------------------- |
| Global  | `~/.claude/commands/`   |
| Project | `.claude/commands/`     |

Commands are invoked as `/command-name` in Claude Code.

## Commands

| Command           | File                         | Description                                      |
| ----------------- | ---------------------------- | ------------------------------------------------ |
| `/commit-message` | `commands/commit-message.md` | Generate a conventional commit message for staged changes (does not commit) |
